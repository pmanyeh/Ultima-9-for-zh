# Ultima IX 按鍵說明（U9-CHT 測試用）

資料來源：遊戲內建的 `Default.kmp`（按鍵設定檔）；作弊鍵來自本機測試用按鍵檔。
這份只整理測試中文化會用到的按鍵，不是完整的遊戲手冊。

---

## 一、移動與操作

| 按鍵 | 功能 |
| --- | --- |
| ↑ ↓ ← →（或數字鍵盤方向鍵） | 前進／後退／左右平移 |
| 空白鍵 | 跳躍 |
| C | 攀爬 |
| CapsLock | 切換走路／跑步 |
| Q 或 ` | 進入／離開「手」模式（拿取、移動物品） |
| X（按住） | 顯示物件名稱（物品名稱翻譯的檢查方式） |
| B | 打開／關閉背包 |
| Shift+Q | 切換主介面顯示（最大／最小／隱藏） |
| Shift+E | 開關裝備介面 |
| Pause | 暫停 |

## 二、日誌、選單與存讀檔（系統訊息檢查重點）

| 按鍵 | 打開的畫面 |
| --- | --- |
| Esc | 主選單（選項／讀取儲存／離開遊戲／製作群） |
| J | 日誌 |
| Ctrl+J／Ctrl+K | 日誌最後一頁／第一頁 |
| Ctrl+Z | 屬性（力量、敏捷、智力、技能等級） |
| Ctrl+T | 歷史 |
| Ctrl+B | 怪物圖鑑 |
| Ctrl+O | 選項（效能、音效） |
| Ctrl+S | 存檔 |
| Ctrl+L | 讀檔 |
| Ctrl+M | 世界地圖 |
| PageUp／PageDown | 書本下一頁／上一頁（遊戲原設定就是這樣對應） |
| Ctrl+X 或 Alt+F4 | 離開遊戲 |

> 結束測試時請用遊戲內選單離開（Esc → 離開遊戲，或 Ctrl+X），不要直接按視窗的 ✕。

## 三、法術書

| 按鍵 | 功能 |
| --- | --- |
| S | 打開法術書 |
| 0 | 基礎法術頁 |
| 1～8 | 第一環～第八環 |
| 9 | 儀式 |
| Ctrl+R | 法術材料（秘藥）頁 |
| Ctrl+G | 詞彙表（力量之語） |

## 四、戰鬥與鏡頭

| 按鍵 | 功能 |
| --- | --- |
| Tab 或 Delete | 進入／離開戰鬥 |
| Z | 防禦 |
| T | 鎖定目標（開／關） |
| N | 切換下一個目標 |
| A | 取消鎖定 |
| M（按住） | 暫時切換第一人稱 |
| K | 切換鏡頭模式 |
| Ctrl+Home／Ctrl+End | 鏡頭拉近／拉遠 |
| Ctrl+方向鍵 | 鏡頭旋轉、俯仰 |
| Ctrl+P | 遊戲內截圖 |

## 五、作弊鍵（只在測試 session 有效）

這些按鍵只有在用 `--keymap .local/p10-misc/keymap/U9CHT-TEST.kmp` 啟動的測試 session 才會生效。
遊戲結束後 finish 會自動還原，原本的 `Default.kmp` 不會被修改。
**零售版是否停用這些指令仍未確認（UNKNOWN），第一次使用時請回報有沒有反應。**

| 按鍵 | 指令 | 預期效果 |
| --- | --- | --- |
| Ctrl+Shift+1 | `fill_spellbook` | 法術書填滿所有法術 |
| Ctrl+Shift+2 | `recharge_mana` | 補滿法力 |
| Ctrl+Shift+3 | `toggle_avatar_fast` | 加速移動（開／關） |
| Ctrl+Shift+4 | `toggle_avatar_fly` | 飛行（開／關） |
| Ctrl+Shift+5 | `toggle_avatar_invulnerable` | 無敵（開／關） |
| Ctrl+Shift+6 | `pass_one_hour` | 時間快轉一小時 |
